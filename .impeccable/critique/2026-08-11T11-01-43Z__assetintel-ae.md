## Overall Impression

The system is real and disciplined where it's been applied deliberately — the two-color rule, the serif-for-numbers rule, and the mega-menu IA all hold up under actual content pressure, which is rare. But the homepage's single highest-impact visual choice (the hero photo) breaks the system's own stated anti-reference, and there's a live correctness bug (not just a design nit) where failed form submissions lie to the user about succeeding. ## Priority Issues

**[P0] Failed lead submissions are reported to the user as successful.** In `app/page.tsx` (`handleOpsSubmit`, ~lines 45-57), the `/api/lead` POST is wrapped in `try { await fetch(...) } catch {}`, and `setOpsSubmitted(true)` fires unconditionally regardless of the actual response status. A visitor whose request fails or 500s sees "Enquiry Received — AssetIntel will review your details and contact you" and never follows up, believing they're already in the pipeline. This is a real lead-loss bug, not a design nit.
- **Why it matters:** Silently loses real leads with zero error signal to the user or a way to know it happened.
- **Fix:** Check `response.ok` before setting success state; show a distinct, styled error state on failure ("Something went wrong — try again or email hello@assetintel.ae").
- **Suggested command:** `/impeccable harden`

**[P1] Hero photography contradicts the project's own committed anti-reference.** The blurred stock photo of two businessmen in a generic glass office is exactly the "flashy real-estate-agent" look DESIGN.md names as forbidden — and it's the single largest, most prominent visual element on the page.
- **Why it matters:** Undermines the "authored, not generic" positioning at the exact moment (the hero) that sets first impression for every visitor.
- **Fix:** Replace with the laptop/stat-mockup treatment alone (already strong and specific), or a bronze/green line-art Dubai skyline consistent with the existing `DecorativeBackdrop` treatment — no stock office photography.
- **Suggested command:** `/impeccable bolder` or `/impeccable polish`

**[P1] Three differently-worded CTAs all route to the same destination, creating recall friction instead of efficiency.** "Analyze Property" (nav), "Analyze My Property" (hero + footer), and "Try The Analyzer" (Rental Strategy Analyzer section) all lead to `/estimator`.
- **Why it matters:** A visitor who already clicked one and bounced back sees what looks like a new, unexplored option — actively works against heuristic #6 (Recognition Rather Than Recall).
- **Fix:** Standardize on a single label site-wide, or make the copy genuinely differentiate distinct actions if they are meant to differ.
- **Suggested command:** `/impeccable clarify`

**[P2] Token drift: 26 detector-flagged one-off colors/font-sizes/radii outside the documented DESIGN.md scale, concentrated in `app/page.tsx` and `components/SiteNav.tsx`.** Confirmed by both assessments — the LLM review spotted `#7A9A8A` by eye; the detector confirmed it plus additional undocumented values (`#9A7238`, `#2A2A2A`, `#EFEAE0` in `SiteNav.tsx`; several one-off `font-size`/`border-radius` values in `page.tsx`).
- **Why it matters:** Consistency and Standards (heuristic #4) scored 4/4 on visible pattern-following, but this quieter, code-level drift is exactly what erodes a design system over time if left unaddressed — each individual instance looks harmless, the accumulation doesn't.
- **Fix:** Audit whether the repeated non-DESIGN.md values (especially `#9A7238`/`#2A2A2A`, used 2x+ each) are an intentional-but-undocumented secondary palette that should be formalized into DESIGN.md, or genuine drift that should be replaced with existing tokens.
- **Suggested command:** `/impeccable audit` then `/impeccable extract`

**[P3] First-screen choice overload undercuts the system's own "restraint" claim.** Between the 7-branch nav, two hero CTAs, and four trust badges (Live DLD Data / Data-Backed / Independent / Built For Dubai) that duplicate content the "Why AssetIntel" section repeats moments later, the very first screen contradicts DESIGN.md's stated philosophy ("earns trust by being quietly correct, not by performing luxury at volume").
- **Why it matters:** Cognitive-load checklist failed on 3 of 8 items (single focus, one-thing-at-a-time, minimal-choices-≤4), all concentrated in this first screen.
- **Fix:** Demote the four trust badges to a single compact strip, or fold them into "Why AssetIntel" below instead of duplicating that section's content in the hero.
- **Suggested command:** `/impeccable distill`

But Casey still faces the same three-CTA redundancy compressed into a narrower column, plus a hamburger menu where Solutions (5 items) and Research (4 items) accordions must both expand before reaching "About" — significant in-menu scrolling for a low-priority destination.
